NEXUS
NEXUS is a menu-driven Python application that stores and manages basic healthcare records for doctors and patients. This is just a prototype.

What It Does
* Add doctors and patients
* Link patients with doctors
* Add prescriptions, appointments, test reports, and reminders
* Update prescriptions and appointments
* View doctor and patient dashboards

Built With
* Python
* SQLite

Note
This project is a **basic prototype for learning and demonstration purposes**.
