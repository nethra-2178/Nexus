# NEXUS

**NEXUS** is a learning-focused healthcare prototype built in Python. It explores how software can act as a *connection point* between doctors and patients by managing basic medical records and offering simple, explainable health insights.
=> NEXUS is **not** a medical diagnosis tool. It is an educational prototype created for learning and experimentation only.

## Why the name “NEXUS”?
The word **nexus** means *a connection or a link* — which is exactly what this project aims to represent: a seamless ecosystem connecting doctors and patients.
There’s also a small (and slightly funny) backstory
While watching the Marvel series **Loki**, I came across an episode titled **“The Nexus Event.”** The word intrigued me, so I looked up its meaning. Later, when I started building this project, that word came straight back to mind — and that’s how **NEXUS** was born.

## Project Structure
This repository currently contains **two related prototypes**:

### 1. NEXUS (Core Prototype)
A **menu-driven Python application** that stores and manages basic healthcare records.
**Features:**
* Add doctors and patients
* Link patients with doctors
* Add prescriptions, appointments, test reports, and reminders
* Update prescriptions and appointments
* View doctor and patient dashboards
This version focuses on **data management and relationships**.

### 2. Nexus.AI (Experimental AI Prototype)
An experimental extension that explores **rule-based health analysis**.
**What it does:**
* Analyzes basic health metrics (e.g., BP, heart rate, blood sugar)
* Uses rule-based logic to simulate early-stage AI reasoning
* Generates human-readable explanations and summaries
* Provides educational health insights (not diagnoses)
This version focuses on **decision logic, explainability, and UX**.
